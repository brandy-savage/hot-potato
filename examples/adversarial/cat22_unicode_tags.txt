# Category 22: Unicode Tag Block Steganography
# Tool names encoded in Unicode Private Use / Language Tag block (U+E0000–U+E007F).
# Each char in the payload maps to its ASCII value + 0xE0000, rendering as zero-width.
# Completely invisible to humans and all standard renderers/editors.
# Model tokenizer ingests tag chars and may reconstruct the original text.
# Scanner gap v1.5.2: no tag-block stripping or decoding.
