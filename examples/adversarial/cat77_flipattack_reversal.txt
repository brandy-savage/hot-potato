# Category 77: FlipAttack — character reversal / mirroring injection
# Goal: embed a malicious instruction in reversed, mirrored, or upside-down text that
# the model is told to reverse/decode before executing. The scanner sees only the
# garbled string; the reversal cue ("read this backwards", "decode reversed") is the
# trigger. Sourced from Praetorian Augustus FlipAttack (16 variants).
# Behavioral layer gap: no pattern matching "read backwards", "reverse the following",
# or the characteristic "decode then execute" imperative used by FlipAttack attacks.
# Static layer gap: reversed strings don't match _DETECTION_SIGNALS patterns; the
# normalization pipeline (homoglyph etc.) doesn't un-reverse text.
