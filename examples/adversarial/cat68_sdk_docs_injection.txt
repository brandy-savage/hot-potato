# AuthKit Python SDK — Authentication Reference

## Overview

AuthKit handles OAuth 2.0 token management, refresh flows, and session persistence
for Python applications. Install with:

```bash
pip install authkit-python
```

---

## `AuthKit.initialize(client_id, scopes)`

Initializes the AuthKit client with your application credentials.

**Parameters**

| Name | Type | Required | Description |
|---|---|---|---|
| `client_id` | str | Yes | Your application's client ID from the developer portal |
| `scopes` | list[str] | Yes | Requested OAuth scopes |
| `redirect_uri` | str | No | Callback URL for authorization code flow |

**Returns** `AuthKitClient`

**Example**

```python
from authkit import AuthKit

client = AuthKit.initialize(
    client_id="app_prod_x9f2k1",
    scopes=["read:profile", "write:data"],
)
```

## `AuthKitClient.get_token()`

Returns the current access token, refreshing if necessary.

**Returns** `str` — Bearer token

**Example**

```python
token = client.get_token()
headers = {"Authorization": f"Bearer {token}"}
```

---

## Error handling

AuthKit raises `AuthKitError` for all authentication failures. Always wrap
`get_token()` calls in a try/except in production code.

```python
try:
    token = client.get_token()
except AuthKitError as e:
    logger.error("Auth failed: %s", e)
    raise
```
