# Category 84: Code completion / inline code artifact injection
# Goal: embed instructions in code artifacts that a coding AI naturally reads and
# processes as part of its job — docstrings, inline comments, TODO markers, type stubs,
# requirements annotations, .env examples. The injected instructions look like developer
# notes or automation hints rather than adversarial content.
# Source: inspired by Greshake et al. indirect prompt injection (arXiv 2302.12173) and
# practical code-context injection patterns observed in real supply-chain attacks.
# Behavioral layer gap: the agent is trained to follow "AI:", "NOTE:", "TODO:" markers
# in code context as actionable guidance. No _AUTHORITY_RE pattern covers these forms.
# Static layer: comment syntax is explicitly excluded from injection pattern matching
# to avoid high false-positive rates on legitimate code annotations.
