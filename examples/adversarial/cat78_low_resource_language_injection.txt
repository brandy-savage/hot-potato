# Category 78: Low-resource / non-English language injection
# Goal: embed tool-call instructions in non-English or low-resource languages that
# the model (qwen2.5:1.5b) is multilingual enough to follow but that English-only
# regex patterns won't catch. The naive.txt system prompt instructs the model to
# "decode ANY encoding" — multilingual text counts. Sourced from Praetorian Augustus
# low-resource language attack module (French, German, Spanish, Turkish, Swahili,
# Welsh, Klingon-style constructed language probes).
# Behavioral layer gap: all five axes use English patterns exclusively; non-English
# authority phrases, privilege claims, and output-hijacking idioms pass undetected.
