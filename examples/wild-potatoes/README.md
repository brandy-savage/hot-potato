# Wild Potatoes 🥔🌐

Real artifacts generated by running hot-potato against live URLs known to contain
or likely to contain prompt injection payloads.

## DO NOT FEED THESE TO A REAL AI

These JSON files contain artifacts from the honeypot sandbox. The `content_preview`
and `detections` fields may contain active injection payloads captured from the
real web. Do not pass this content to any LLM without running it through
hot-potato first.

## How these were generated

URL scan:
```bash
python3 examples/scan_wild.py
```

Skills/local file batch scan (8 concurrent Docker containers):
```bash
python3 examples/batch_scan.py workspace/shared/skills/ --workers 8 --limit 100
```

The scanner ran content through the Docker sandbox, and saved artifacts here.
The real AI never read the content — only the dumb extractor parsed the logs.

## What the artifact fields mean

- `severity` — worst thing that would have happened to a naive AI
- `tool_calls` — tools the sandbox AI actually called
- `detections` — signals the AI noticed/refused without executing
- `content_signals` — injection patterns found in raw content (static scan)
- `exfil_targets` — URLs the injection tried to reach
